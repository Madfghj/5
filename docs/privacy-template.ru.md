## Кто обрабатывает данные

Оператор: **[юридическое имя / организация]**. Адрес: **[адрес]**. Контакт по вопросам данных: **[действующий email]**. Публичная страница поддержки: **[URL]**.

## Какие данные использует приложение

Приложение использует выбранное имя, язык интерфейса, идентификатор аккаунта, членство в группах, приглашения, названия и время событий, места, заметки и ответы «Да / Нет / Пока не знаю».

При входе через Google, Apple или Microsoft приложение получает идентификатор пользователя у соответствующего провайдера и **[перечислить фактически сохраняемые профильные поля, например email]**. Пароль провайдера не передаётся OpenCalendar.space. Подробности обработки у провайдера описаны в его собственной политике.

Для доступа к API используется токен сессии. В браузере и мобильной оболочке сохраняются **[точный перечень локальных данных]**. Сервер может обрабатывать технические сведения запросов, включая **[реальная конфигурация логирования, IP, срок хранения]**.

Не помещайте в общие события информацию, которую не хотите показывать участникам группы. Код приглашения предоставляет возможность присоединиться к группе; передавайте его только выбранным людям.

## Зачем нужны данные

Данные нужны для входа, сохранения календаря, совместного доступа участников и передачи обновлений. Правовые основания обработки: **[указать основания, применимые к оператору и аудитории]**.

## Кто видит данные

Участники группы видят её события, список участников и их ответы. Уполномоченные администраторы инфраструктуры имеют доступ в объёме, необходимом для работы сервиса. Используемые хостинг, регион хранения и субподрядчики: **[перечень, страны, назначение]**. Международная передача и применяемые гарантии: **[описание либо обоснованное отсутствие]**.

Приложение в текущем исходном проекте не подключает рекламные или аналитические SDK. **[Подтвердить это после добавления всех нативных зависимостей и инфраструктуры.]**

## Сроки хранения и удаление

Данные аккаунта хранятся **[точный срок / критерий]**, резервные копии — **[срок]**, технические логи — **[срок]**. Удаление аккаунта доступно в настройках приложения. Результат удаления общих событий и ответов: **[сверить с текущей реализацией и описать]**. Данные в резервных копиях удаляются **[процедура и срок]**.

Публичная инструкция по удалению без установленного приложения: **[URL и механизм проверки личности]**. Обращения по доступу, исправлению, выгрузке и удалению: **[email / форма]**. Если применимо, укажите порядок обращения к компетентному органу: **[данные]**.
